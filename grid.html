O que é o CSS Grid?

O CSS Grid Layout organiza elementos em duas dimensões: linhas e colunas ao mesmo tempo. Você desenha a grade no contêiner e os filhos diretos ocupam as células. 

.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
}

Vocabulário básico

TermoSignificado
Contêiner (grid container)O elemento com display: grid
Item (grid item)Filho direto do contêiner
Coluna e linha (trilhas)Os espaços verticais e horizontais da grade
CélulaCruzamento de uma linha com uma coluna
Linha de grade (grid line)A divisão entre trilhas. É numerada a partir de 1
ÁreaRegião formada por uma ou mais células
frFração do espaço livre do contêiner

💡 Flexbox ou Grid? O Flexbox organiza em uma direção por vez, a partir do conteúdo. O Grid organiza em duas direções, a partir do layout. Os dois se combinam bem. Veja a página de Flexbox.

Posicionando e expandindo itens

As linhas de grade são numeradas. Uma grade com 3 colunas tem 4 linhas verticais (1, 2, 3 e 4). O último número também pode ser escrito como -1. 

/* ocupa da linha 1 até a linha 3 (2 colunas) */
grid-column: 1 / 3;

/* equivalente, usando span (ocupar 2 colunas) */
grid-column: span 2;

/* ocupa da linha 2 até a linha 4 (2 linhas) */
grid-row: 2 / 4;

Exemplo: A ocupa 2 colunas e C ocupa 2 linhas. Os outros itens preenchem os espaços livres.

Áreas nomeadas

Com grid-template-areas você desenha o layout em texto. Cada palavra é o nome de uma área, e cada linha de texto é uma linha da grade. Depois, cada item escolhe sua área com grid-area. 

.layout {
  display: grid;
  grid-template-columns: 1fr 3fr;
  grid-template-areas:
    "topo   topo"
    "menu   conteudo"
    "rodape rodape";
}

.topo     { grid-area: topo; }
.menu     { grid-area: menu; }
.conteudo { grid-area: conteudo; }
.rodape   { grid-area: rodape; }

📱 Em telas de até 600px, o CSS redesenha as áreas em uma única coluna (topo, menu, conteúdo, rodapé). Reduza a janela para ver. Esta é a grande vantagem das áreas: mudar o layout sem mexer no HTML.

Grid responsivo

1. Com media query

Troque o número de colunas conforme a largura da tela. Reduza a janela abaixo de 600px.

.galeria {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 10px;
}

@media (max-width: 600px) {
  .galeria {
    grid-template-columns: 1fr;   /* uma coluna só */
  }
}

2. Sem media query: auto-fit e minmax

minmax(140px, 1fr) diz que cada coluna tem no mínimo 140px e no máximo uma fração do espaço. Com auto-fit, o navegador calcula sozinho quantas colunas cabem. O index.html deste hub usa exatamente essa técnica. 

.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(140px, 1fr));
  gap: 10px;
}

3. auto-fit ou auto-fill?

A diferença aparece quando há poucos itens. O auto-fill mantém as colunas vazias. O auto-fit recolhe as colunas vazias, e os itens esticam.

PropriedadeFunção

grid-template-columnsDefine as colunas
grid-template-rowsDefine as linhas
grid-auto-rowsAltura das linhas criadas automaticamente
gapEspaço entre linhas e colunas
grid-template-areasDesenha o layout com nomes de áreas
place-itemsAlinha os itens dentro das células

Propriedades dos itens

PropriedadeFunção
grid-columnPosição e largura em colunas (1 / 3, span 2)
grid-rowPosição e altura em linhas
grid-areaEscolhe uma área nomeada
